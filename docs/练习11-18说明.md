## 11 模块导入

**目标**：搞懂 `from common.client import HttpClient` 是怎么找着文件的。

```python
import json                       # 导入整个模块，用的时候写 json.xxx
from pathlib import Path          # 只导入其中一个名字，直接用 Path
import json as j                  # 起别名
from json import dumps            # 只拿一个函数
```

```python
print("搜索起点(第1条):", sys.path[0])
```

`sys.path` 是 Python 找模块的**目录清单**。你项目里能写 `from common.client import ...`，是因为**项目根目录在清单里**（PyCharm 自动加的）。

**跑**：PyCharm 右键 Run
**预期**：

```
{"a": 1}
api_auto\data\x.yaml
搜索起点(第1条): C:\Users\A\PycharmProjects\api_auto\练习
{"b": 2} {"c": 3}
```

> 注意第 1 条搜索路径是**当前脚本所在目录**。这就是为什么在终端用 `python 练习/04.py` 会找不到 `common`——那时起点是 `练习/`，不是项目根。

**对应项目**：`testcases/test_auth.py` 顶部的 `from common.client import HttpClient`。

## 12 装饰器原理

**目标**：`@pytest.fixture` 到底干了什么。

```python
def my_decorator(func):
    def wrapper():
        print("--- 前：准备 ---")
        func()
        print("--- 后：收尾 ---")
    return wrapper


@my_decorator
def say_hi():
    print("hi，我是本体")
```

**这一行 `@my_decorator` 完全等价于：**

```python
say_hi = my_decorator(say_hi)
```

所以 `say_hi` 这个名字还在，但**里面已经被换成 `wrapper` 了**。跑完打印 `say_hi.__name__` → `wrapper`，就是铁证。

**跑**：右键 Run
**预期**：

```
--- 前：准备 ---
hi，我是本体
--- 后：收尾 ---
现在 say_hi 的真身: wrapper
```

**对应项目**：`@pytest.fixture` 把函数登记进 pytest 的货架（你自己写 `def cart()` 不加它就报 not found）；`@allure.story("...")` 给用例加报告分组。

**一句话**：装饰器 = **给函数套一层壳，不改名换内脏**。

## 13 元组与解包

**目标**：看懂 saucedemo 里 `USERNAME = (By.ID, "user-name")` 这种写法。

```python
point = (3, 5)
x, y = point          # 解包：一次给两个变量赋值
```

`return "张三", 18` 看着像返回两个值，**其实返回的是一个元组** `("张三", 18)`，接收时再解包。

```python
a, b = 1, 2
a, b = b, a           # 交换，不需要临时变量
```

**跑**：右键 Run
**预期**：

```
3 5
张三 18
2 1
定位方式: id | 定位值: value
```

（最后一行实际是 `定位方式: id | 定位值: user-name`）

**对应项目**：selenium 的 `find_element(*locator)` —— 那个 `*` 就是把元组拆成两个参数。

## 14 文件读写 + json

**目标**：第 6 周 extract 机制要用（把 token 写进文件、再读出来）。

```python
p.write_text(json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8")
back = json.loads(p.read_text(encoding="utf-8"))
```

| 函数 | 方向 | 结果 |
|---|---|---|
| `json.dumps(字典)` | 字典 → 字符串 | `str`，用来写文件、发请求 |
| `json.loads(字符串)` | 字符串 → 字典 | `dict`，用来在代码里取值 |

`ensure_ascii=False` 保证中文正常显示；`indent=2` 让格式好看；`encoding="utf-8"` 避免 Windows 乱码。

**跑**：右键 Run
**预期**：

```
读回来: {'token': 'abc123', 'user': '张三'}
取字段: abc123
<class 'str'>
<class 'dict'>
```

## 15 嵌套字典与 get

**目标**：`resp.json()["category"]["name"]` 怎么来的，以及怎么避免崩。

```python
resp["category"]["name"]     # 一层一层往里走
resp.get("price")            # 字段不存在 → None，不报错
resp.get("price", 0)         # 不存在就用默认值 0
```

**关键区别**：

| 写法 | 字段不存在时 |
|---|---|
| `resp["price"]` | 崩：`KeyError` |
| `resp.get("price")` | 返回 `None`，继续跑 |

**跑**：右键 Run
**预期**：

```
衣服
None
0
2
KeyError: 'price'
```

**测开怎么用**：断言必填字段时用 `["xxx"]`（缺了就该红）；取可选字段时用 `.get()`。

## 16 类属性 vs 实例属性

**目标**：为什么定位器要写在类里、而不是 `__init__` 里。

```python
class LoginPage:
    USERNAME = ("id", "user-name")     # 类属性：所有对象共享一份

    def __init__(self, name):
        self.name = name               # 实例属性：每个对象各一份
```

**跑**：右键 Run
**预期**：

```
('id', 'user-name') ('id', 'user-name')     ← 两个对象读到同一个
页面A 页面B                                   ← 各自的
('id', 'changed') ('id', 'changed')          ← 改类属性，全变
改名了 页面B                                  ← 改实例属性，只影响自己
```

**对应项目**：`LoginPage.USERNAME`、`LoginPage.PASSWORD` 那些大写常量。它们对每个页面对象都一样，没必要每个对象存一份。

## 17 pytest.raises（唯一一个要用 pytest 跑的）

**目标**：怎么测“这个操作就应该报错”。

```python
def test_除以零应该抛异常():
    with pytest.raises(ZeroDivisionError):
        1 / 0
```

意思是：**我预计这段代码会抛 `ZeroDivisionError`，没抛就算用例失败**。

还能顺便检查错误消息：

```python
with pytest.raises(ValueError) as e:
    raise ValueError("用户名不能为空")
assert "不能为空" in str(e.value)
```

**跑**（必须用 pytest）：

```
pytest 练习/test_17_raises.py
```

**预期**：`3 passed`

**对应项目**：测“密码错误应该 401”“假 token 应该被拒”——虽然那些是断言状态码不是异常，但思路一致：**反向用例比正向更有价值**。

## 18 lambda 与 key

**目标**：一行找出最贵/最便宜的商品。

```python
best = max(items, key=lambda x: x["price"])
```

`key=` 的意思是“**按什么比大小**”。`lambda x: x["price"]` 是一个**一句话的小函数**：给我一个 `x`，我还你 `x["price"]`。

它等价于：

```python
def get_price(x):
    return x["price"]


max(items, key=get_price)
```

**跑**：右键 Run
**预期**：

```
最贵: 299
最便宜: 10
最贵的商品: 外套 299
最便宜的商品: 卫衣 10
按价格排序: ['卫衣', 'T恤', '外套']
用普通函数也一样: 外套
```

> `max(prices)` 拿到的是**价格数字**；`max(items, key=...)` 拿到的是**整个商品字典**。做测试要后者——因为你要拿它的标题去断言。
